# FeedCourier Plugin API v1

FeedCourier `v0.3.1+` runs third-party and official **Channel Plugins** and **Processor Plugins** as **single-file ES Modules (`plugin.js`)** directly inside an embedded pure-ECMAScript (ES2024) sandbox — no sidecar containers, no Node.js runtime dependency in production, and one-click installation from the marketplace.

TypeScript declarations live in [`v1.d.ts`](./v1.d.ts).

---

## Execution Environment & Constraints

1. **Single-file ES Module**: Every plugin release is a single self-contained `plugin.js` file with **zero `import` statements** (static or dynamic).
2. **Synchronous execution**: Exported hooks (`validate`, `test`, `deliver`, `onRender`, `onDelivered`) execute synchronously and call `fc.fetch(...)` synchronously. Do not return Promises or use `async`/`await`.
3. **Pure ECMAScript + `globalThis.fc` only**:
   - Available: standard ES2024 built-ins (`JSON`, `RegExp`, `Math`, `Date`, `String`, `Array`, `Object`, `Map`, `Set`, `encodeURIComponent`, `decodeURIComponent`, etc.) plus `globalThis.fc`.
   - **Not available**: Node.js and WHATWG Web APIs (`new URL(...)`, `URLSearchParams`, `Buffer`, `TextEncoder`, `TextDecoder`, `AbortSignal`, `fetch`, `crypto`, `console`, `process`, `setTimeout`). Use pure JS + `fc.*` instead.
4. **Resource limits**: Each invocation runs under strict host CPU instruction, memory, and HTTP timeout budgets.

## Host API (`globalThis.fc`)

| Method | Signature | Description |
| --- | --- | --- |
| `fc.fetch` | `(req: { method?, url, headers?, body?, timeoutMs? }) => { status, ok, headers, body }` | Synchronous SSRF-protected HTTP request (no redirects). Response `headers` keys are lowercased. Throws `Error` on network, timeout, or host-policy errors — always wrap in `try/catch`. |
| `fc.sha256` | `(input: string, enc?: "hex" \| "base64") => string` | SHA-256 hash of UTF-8 input. |
| `fc.md5` | `(input: string) => string` | Lowercase hex MD5 hash of UTF-8 input. |
| `fc.hmacSha256` | `(msg: string, secret: string, enc?: "hex" \| "base64") => string` | HMAC-SHA256 digest. |
| `fc.base64Encode` | `(input: string) => string` | Standard Base64 encode (UTF-8). |
| `fc.base64Decode` | `(input: string) => string` | Standard Base64 decode to UTF-8. |
| `fc.base64UrlEncode` | `(input: string) => string` | URL-safe Base64 encode without `=` padding. |
| `fc.utf8ByteLength` | `(input: string) => number` | Exact UTF-8 byte count of a string. |
| `fc.truncateUtf8Bytes` | `(input: string, maxBytes: number) => string` | Safe UTF-8 truncation on Unicode scalar value boundaries (`<= maxBytes`, zero broken surrogate pairs). |
| `fc.htmlToText` | `(html: string) => string` | Convert HTML content to clean plain text. |
| `fc.unixNow` | `() => number` | Current Unix epoch seconds. |
| `fc.uuid` | `() => string` | Generate a random UUID v4. |

## Exporting `meta`

Every `plugin.js` must export a static `meta` object conforming to [`schema/manifest.schema.json`](../../schema/manifest.schema.json):

```js
export const meta = {
  id: "ntfy",
  name: "ntfy Push",
  version: "0.3.1",
  api_version: "1",
  kind: "channel", // "channel" | "processor"
  min_core: "0.3.1",
  category: "delivery", // links | content | media | delivery | analytics | security | other
  icon: "bell",
  description: {
    en: "Concise English description.",
    zh: "简洁的中文说明。",
  },
  homepage: "https://feedcourier.ellery.me/plugins/js-plugins",
  repository: "https://github.com/ElleryHe/FeedCourier-Plugins/tree/main/plugins/channels/ntfy",
  allowed_hosts: ["ntfy.sh"],
  hooks: [],
  permissions: ["network"],
  account_schema: { /* JSON Schema for account form */ },
  destination_schema: { /* JSON Schema for destination form */ },
  capabilities: { supports_html: false, max_text_len: 4096 },
};
```

### Secret Fields

Any property in `account_schema`, `destination_schema`, or `instance_schema` with `"format": "password"` is automatically encrypted at rest by FeedCourier, masked in WebUI/API responses, and preserved across partial config updates.

## Channel Plugin Exports (`kind: "channel"`)

### `validate(ctx)`

Validates and normalizes user-submitted account or destination configuration before saving:

- Input: `{ scope: "account" | "destination", config: Record<string, unknown> }`
- Output: `{ ok: true, normalized_config }` or `{ ok: false, error: "..." }`

### `test(ctx)`

Runs an interactive connectivity check from the WebUI:

- Input: `{ scope: "account" | "destination", account, destination }`
- Output: `{ ok: true, message: "..." }` or `{ ok: false, error: "..." }`

### `deliver(ctx)`

Delivers a single RSS entry to the target channel:

- Input (`DeliverContext`):
  ```json
  {
    "idempotency_key": "task-123",
    "account": {},
    "destination": {},
    "entry": {
      "title": "Article Title",
      "url": "https://example.com/post",
      "summary_text": "Clean summary",
      "plain_text": "Full plain text",
      "content_html": "<p>Full HTML</p>",
      "author": "Alice",
      "published_at": 1764023400,
      "published_local": "2026-11-25 06:30",
      "media": []
    },
    "feed": {
      "id": 1,
      "title": "Hacker News",
      "url": "https://news.ycombinator.com/rss",
      "site_url": "https://news.ycombinator.com",
      "favicon_url": "https://news.ycombinator.com/favicon.ico"
    },
    "route": {
      "id": 1,
      "name": "Daily Digest",
      "locale": "en",
      "timezone": "Asia/Shanghai"
    },
    "checkpoint": null
  }
  ```
- Output (`DeliverResult`):
  - Success: `{ outcome: "delivered", external_id?: "..." }`
  - Transient error (network failure, HTTP `429`, HTTP `5xx`): `{ outcome: "retry", retry_after_secs?: 60, diagnostic?: "..." }`
  - Permanent error (invalid config, HTTP `4xx` except `429`): `{ outcome: "permanent_failure", diagnostic?: "..." }`

## Processor Plugin Exports (`kind: "processor"`)

Declare at least one hook in `meta.hooks` (`"on_render"` and/or `"on_delivered"`) and export:

- `onRender(ctx)` (receives `{ idempotency_key, plugin_id, instance_config, route_option, entry, feed, route, write_cache }`) → `{ outcome?: "continue", primary_link?, content_html?, warnings? }` or `{ outcome: "retry", retry_after_secs?, diagnostic? }` (any returned `content_html` is re-sanitized via `ammonia`)
- `onDelivered(ctx)` (receives `{ event: "on_delivered", idempotency_key, payload }`) → `{ ok?: true, warnings? }`

---

## Security & Network Policy

- Outbound requests via `fc.fetch` are enforced by FeedCourier's SSRF guard (cloud metadata IPs and HTTP 3xx redirects are unconditionally blocked).
- Plugins must declare default upstream domains in `meta.allowed_hosts` (normalized lowercase bare hostnames or `*.example.com`, never metadata IPs). Admin-configured `format: "uri"` fields in account/instance config automatically grant exact `(scheme, host, port)` origin access for self-hosted servers.
- Marketplace installations verify the exact `sha256` digest of `plugin.js` published in `index.json` before persisting or executing the code.

## Local Testing

Use Node.js 24+ built-in test runner (`node --test`) with a mock `globalThis.fc` matching the host API (see [`tests/ntfy.test.mjs`](../../tests/ntfy.test.mjs) and [`tests/bark.test.mjs`](../../tests/bark.test.mjs)):

```bash
node scripts/build-index.mjs --check
node --test tests/*.test.mjs
```
